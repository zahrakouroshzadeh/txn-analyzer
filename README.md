## About txn-analyzer
A C++ tool for analyzing synthetic transaction streams

## WebAssembly Demo

Try the live WebAssembly demo:
- Main: [https://zahrakouroshzadeh.github.io/txn-analyzer/](https://zahrakouroshzadeh.github.io/txn-analyzer/)
